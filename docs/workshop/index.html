Dendrometer Data Analysis Workshop

A hands-on pathway from raw dendrometer and climate records to biological phases, growth fitting, climate relationships, and time-frequency analysis.

Start the workshop → Install the R package ↗

Workshop goals

Build a complete and reproducible workflow.

By the end of the workshop, participants should be able to:

Import and diagnose

Read dendrometer and climate files, identify their temporal resolution, and diagnose irregularities.

Prepare time series

Resample, truncate, smooth, standardise, detrend, aggregate, and interpolate missing values.

Extract stem dynamics

Estimate daily behaviour, zero-growth phases, stem-cycle phases, and TWD maxima.

Fit growth curves

Fit single and double growth functions and compare their performance.

Integrate climate

Join climate variables at daily, subdaily, and biological-phase scales.

Analyse responses

Study event-centred responses, moving correlations, and wavelet patterns.

Curriculum

Seven modules plus exercises.

The sequence follows the analysis path used in the workshop source material.

01

Import, resampling, and cleaning

Read files, check resolution, remove artefacts, interpolate gaps, and standardise time steps.

02

Standardisation and detrending

Prepare comparable signals and isolate the temporal components needed for analysis.

03

Daily and phase analysis

Calculate daily metrics and extract zero-growth and stem-cycle phases.

04

Growth fitting

Fit single and double growth functions and evaluate their performance.

05

Climate integration

Harmonise and attach meteorological variables across relevant temporal scales.

06

Events, correlations, and wavelets

Assess event responses, moving climate relationships, periodicity, and coherence.

07

Function catalogue

Use the package-wide reference for public functions and their variations.

08

Practical exercises

Apply the workflow to dendrometer and climate datasets step by step.

Start every session with

Load the setup and data once.

The setup script prepares the workshop functions and returns the dendrometer and climate objects used throughout the modules.

R · session setup
source("00_setup.R")
workshop_data <- load_workshop_data()
dm <- workshop_data$dm
clim <- workshop_data$clim

names(dm)
names(clim)

Data-loading options

Use workshop examples or your own files.

Automatic

Start immediately

The loader checks data/raw/, then the package examples, and finally creates simulated data if neither source is available.

Explicit

Control the import

Provide dendrometer and climate file paths and pass delimiter, decimal, time-column, and timezone settings to the readers.

R · explicit files
workshop_data <- load_workshop_data(
  dm_file = "data/raw/dendrometer.csv",
  clim_file = "data/raw/climate.csv",
  tz = "UTC",
  dm_args = list(sep = ";", dec = ",", datetime_col = 1),
  clim_args = list(sep = ";", dec = ",", time_col = "TIME")
)
