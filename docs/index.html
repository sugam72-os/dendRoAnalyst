Biological phase extraction

Two views of stem dynamics.

Use the method that matches your research question, then apply unified summaries and plotting methods to the returned objects.

phase.sc()

Stem-cycle approach

Separates contraction, expansion, and increment phases to describe the cyclic dynamics of stem shrinkage and recovery.

contractionexpansionincrement
phase.zg()

Zero-growth approach

Separates irreversible radial growth from reversible tree water deficit using the running stem-radius maximum as a reference.

Quick start

From data to phases in a few calls.

The package includes example dendrometer and ERA5-Land climate datasets, so you can reproduce the workflow before using your own records.

R · reproducible example
library(dendRoAnalyst)

# Load the bundled subdaily example
data(gf_nepa17)

# Inspect and standardise resolution
resolution <- reso_dm(gf_nepa17[[1]])
dm_hourly <- dendro.resample(
  df = gf_nepa17,
  by = "H",
  value = "mean"
)

# Calculate daily statistics
daily_out <- daily.data(
  df = dm_hourly,
  TreeNum = 1
)
# Stem-cycle phases
sc_out <- phase.sc(
  df = gf_nepa17,
  TreeNum = 1
)

# Zero-growth phases
zg_out <- phase.zg(
  df = gf_nepa17,
  TreeNum = 1,
  smoothing = 6
)

plot(zg_out, temporal = "monthly", type = "twd")
plot(zg_out, temporal = "monthly", type = "abr")
data(ktm_clim_hourly)

zg_climate <- dm_join_phase_clim(
  zg_out,
  ktm_clim_hourly,
  mean_vars = c("temp", "VPD", "RH"),
  max_vars  = c("temp", "VPD"),
  sum_vars  = "prec"
)

head(zg_climate$ZG_cycle)

Beyond phase extraction

Built for complete analyses.

Core functions share consistent output classes, summaries, and plotting methods across daily, seasonal, and time-frequency workflows.

A / 06

Daily summaries

Minima, maxima, amplitude, timing, lag, and daily stem status from high-frequency records.

B / 06

Climate coupling

Join dendrometer and meteorological variables across subdaily, daily, and phase-level scales.

C / 06

Growth fitting

Fit and compare mathematical growth functions, evaluate fit quality, and extract phenological timing.

D / 06

Event analysis

Quantify stem responses during adverse-climate episodes and the subsequent recovery phase.

E / 06

Climate relationships

Detrend and standardise series, calculate moving correlations, and run superposed epoch analysis.

F / 06

Wavelet tools

Inspect periodicity, reconstruct selected frequencies, and analyse dendrometer–climate coherence.
